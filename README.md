# Python Expense Tracker

A beginner-friendly Python project improved step by step while practicing programming and basic data-handling fundamentals.

## Version 5 - Category-wise Expense Summary

Version 5 reads the saved `expenses.csv` file and uses a Python dictionary to calculate total spending for each category.

### Current Features

- Enter 3 expenses and categories
- Calculate total, average, highest, and lowest expense
- Save expenses to CSV
- Read saved CSV data
- Display saved expenses
- Calculate category-wise totals from the CSV

## New Concepts Practiced

- Python dictionaries
- Checking whether a key already exists
- Updating running totals
- `dict.items()`
- Grouping simple data by category
- Combining CSV reading with basic aggregation

## Example Category Summary

```text
--- Category Summary ---
Food: ₹650.00
Travel: ₹500.00
Shopping: ₹300.00
```

The exact output depends on the expenses entered when the program runs.
